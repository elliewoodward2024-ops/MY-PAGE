CTF CHALLENGE PAGE

About

This creation is a little CTF Challenge Page!
The idea of this page was to create a selection of easy to hard challenges that cover a range of different cryptography cyphers as well as web exploration challenges. Creating a CTF style challenge website to learn, problem solve, and explore cybersecurity areas.
On this page (if you want to have a go) all resources needed to solve the cryptography challenges are provided in the tools section on the challenge page. (Though I do encourage writing your own scripts or hand solving the problem where you are able too.) However to complete the web exploration style challenges you will need to be able to use the inspect tool on your computer. (The image to the left is not the correct colouring).
